All six crash scenarios were analyzed in code and simulated directly against **PostgreSQL 16.16** using controlled provider faults and worker lease manipulation.

> **Important Epistemic Boundary:** External HTTP providers (such as Kavenegar) do not participate in two-phase commit with PostgreSQL. An HTTP timeout or post-response process termination does **not** prove the provider rejected or never accepted the SMS. This architecture guarantees **at-least-once** dispatch recovery with bounded retry / operator-triage safeguards, **not** mathematical exactly-once delivery across mid-dispatch crashes.
